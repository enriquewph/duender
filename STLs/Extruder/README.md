# Extruder

Extruder-related parts for Duender.

Current layout:

- `dragonburner/`
- `mount/`
- `sherpa_mini/`

Each subfolder contains:

- `step/` (exchange CAD)
- `stl/` (printable mesh)

Some parts include variants for M3x4 / M3x4.5 heat-set inserts.
